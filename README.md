# AdTech Product Analytics & Revenue Optimization

Original portfolio project built around an AdTech product-analytics workflow.

**Business flow:** Impressions → Clicks → Conversions → Revenue → Product recommendation → A/B test.

## Stack
SQL (CTEs, joins, window functions) • Python (Pandas, NumPy, SciPy) • Power BI-ready dashboard specification • A/B testing

## Questions
- Which markets, devices, ad types and placements perform best?
- Where are engagement/conversion bottlenecks?
- Which publishers/segments need optimization?
- Does a treatment placement improve conversion?
- What product experiments should be prioritized?

## Structure
`data/` synthetic event data  
`sql/` analytical SQL  
`python/` EDA and experiment analysis  
`docs/` case study, metrics and resume bullets  
`dashboard/` Power BI build specification

**Portfolio note:** synthetic data; not affiliated with or based on confidential Media.net data.
