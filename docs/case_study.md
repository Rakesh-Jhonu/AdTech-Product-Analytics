# Product Analytics Case Study

## Business context
An advertising platform needs to maximize useful engagement and monetization while maintaining product quality across markets, devices, ad types and placements.

## Analytical workflow
1. Define product/business questions.
2. Validate event data.
3. Build KPI layer with SQL.
4. Segment performance by market, device, ad type, placement, publisher and advertiser.
5. Diagnose funnel drop-offs.
6. Evaluate treatment vs control.
7. Convert evidence into product hypotheses.
8. Define success and guardrail metrics for follow-up experiments.

## Product recommendation framework
**Observation → Opportunity → Hypothesis → Experiment → KPI → Decision rule**

This project intentionally uses synthetic data for portfolio purposes.
