# Metric Dictionary

| Metric | Definition |
|---|---|
| Impressions | Number of ad displays |
| Clicks | User clicks |
| CTR | Clicks / Impressions |
| Conversions | Completed conversion actions |
| Conversion Rate | Conversions / Clicks |
| Revenue | Advertising revenue |
| Cost | Estimated delivery/acquisition cost |
| Profit | Revenue - Cost |
| RPM | Revenue / Impressions × 1000 |

For aggregated reporting, calculate ratios from aggregated numerators and denominators.
